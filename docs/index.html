FAQ

Do these QR codes expire?

The code stores your original content directly. If it contains a link, keep the destination online for the link to keep working.

Which format should I use for print?

Use SVG or PDF for print. Both are vector formats that stay sharp as you resize them.

What is a quiet zone?

The quiet zone is the blank border around the code. Leave at least four squares of space on each side so scanners can pick out the code.

What are the system requirements?

The download requires a Mac with Apple Silicon and macOS 13 (Ventura) or later.

How do I build the app from source?

Install the Xcode Command Line Tools, then run this command. The app appears inside the cloned repository at build/QR Generator.app.

$ git clone https://github.com/Ajtn05/Quick-QR.git && ./Quick-QR/build.sh
